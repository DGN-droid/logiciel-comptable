# logiciel-comptable

A modern web-based accounting management software designed to streamline financial tracking, invoice management, and reporting. Built with Next.js, TypeScript, and Tailwind CSS for speed, security, and responsiveness.

---

### Features

- **Financial Dashboard**: Overview of key financial metrics, income, and expenses.
- **Responsive Interface**: Fully responsive UI components built with Tailwind CSS.
- **State Management**: Centralized application state using React Context API.
- **Modern Architecture**: Built with Next.js App Router and TypeScript for strong type safety.
